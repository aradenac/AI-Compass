Étapes distinctes de mise à disposition

01 · Benchmark qualifié

Run individuel accepté et configuration candidate, sans visibilité automatique.

02 · Publication éditoriale

Décision Workgroup et guides applicables ; peut être révoquée.

03 · Disponibilité personnelle

Éligibilité, droits/licences et installation testée.

04 · Première utilisation

Utilisation déclarée sur une activité réelle.

La matrice ne provisionne pas les comptes. Dans la version Server, chaque changement reste autorisé, attribué et journalisé. Le suivi de l'utilisation réelle porte sur une tâche et une ou plusieurs personnes, pas simplement sur la publication d'une configuration.
